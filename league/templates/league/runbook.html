Season runbook

The commissioner's year, in order: from the end of the {{ league_season }} season to the start of the {{ next_season }} season. Each step says where it happens: Fantrax, the console, the admin, or your computer (a local copy of the repo). The commissioner guide explains each part in more detail.

1. The season ends

  1. Admin → Final standings: one row per team, 1 = champion. They set the {{ next_season }} farm draft order. Check it under Farm picks → Draft order.
  2. Admin → Budget adjustments: any missed-IP penalties not yet entered.
  3. Your computer: save the end-of-season snapshot, which sets every new contract's price. 
    uv run python scripts/fantrax_snapshot.py <league id> data/fantrax/{{ league_season }}-final
    Commit it and deploy. The league ID is in Admin → Fantrax leagues, or the Fantrax URL.
  4. Console → Sync from Fantrax, and resolve any exceptions.

2. Offseason trading

  1. Fantrax: renew the league for {{ next_season }}.
  2. Console → Find new Fantrax leagues, then add the renewed league. Offseason trades happen in the new league; the sync reads both.
  3. Console → Sync from Fantrax as often as you like, resolving exceptions as they come.
  4. Console → Sync from Discord: cash trades are posted in the league Discord's #trades-<year>-assets channels; the sync reads them. Resolve any Discord exceptions.
  5. Admin: enter farm pick trades as they're agreed.

3. Blackout and signing

Trading stops for the blackout, at most a week by the rulebook. Tell the league when it starts.

  1. Console → Sync from Fantrax and Sync from Discord once trades stop, and resolve every exception. Signing can't open while any are listed.
  2. Your computer: save the blackout snapshot, which sets who's on each roster. 
    uv run python scripts/fantrax_snapshot.py <new league id> data/fantrax/{{ league_season }}-blackout
    Commit it and deploy.
  3. Console → Load rosters: pick the blackout snapshot from the list. Fix whatever the checklist shows (contracts not on their team's roster, players without a salary), then reload if needed.
  4. Console → Open signing. Optionally set a deadline in Admin → Signing periods, and tell the league.
  5. Console → Teams table: follow up on teams that haven't submitted or have problems.
  6. Console → Lock signing when every team is ready. This can't be undone from the console. New contracts and budgets are published to every team.

4. Draft day

  1. Console → The {{ next_season }} season: enter the farm draft start and the auction start (Eastern). Do it straight after locking: the sync refuses to run until they're in, and moves synced before them would be filed under the wrong season.
  2. Fantrax: run the farm draft (teams add picks as ordinary claims), then the auction.
  3. Console → Sync from Fantrax once the auction has started. The first sync after the auction start freezes every team's auction budget. Resolve any exceptions (a farm claim by a team with no pick left, say).
  4. Console → Start the {{ next_season }} season once its checklist is all green. That makes {{ next_season }} current and adds the next year of farm picks.

5. During the season

  • Console → Sync from Fantrax every week or two: trades, drops (buyouts), promotions and MLB debuts. Resolve exceptions as they come.
  • Console → Sync from Discord now and then, for cash trades posted in the trade channels.
  • Admin: missed-IP penalties and farm pick trades.
  • Fantrax cookie: when the console says the login has expired, copy a fresh Cookie header from a logged-in Fantrax tab into secrets/fantrax_cookie.txt on your computer, then run 
    scripts/set_render_secret.sh FANTRAX_COOKIE secrets/fantrax_cookie.txt
    It sets the value on Render without printing it and redeploys.

Known gaps

Fix these before they bite. Until then, work around them by hand.

  • Signing prices (#64): Load rosters always reads prices from 2026-final. Fine for the signing after 2026; must be fixed before the signing after 2027 (Feb 2028).
  • Two renewed leagues (#50): after the October 2027 renewal, both leagues apply roster facts. Fix before then, or deactivate the older league in Admin → Fantrax leagues once its moves are synced.
  • Fantrax credentials (#65): the cookie and Secret ID are Render settings, so changing them needs the script above and a redeploy.
